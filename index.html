What is Mycelium?

Mycelium is a coordination layer for multi-agent systems. Agents join shared rooms, write to a persistent semantic memory, and negotiate decisions through a structured protocol. Intelligence compounds across sessions — what one agent learns, every future agent inherits.

Read the full docs for the architecture, CLI reference, and adapter guides.
