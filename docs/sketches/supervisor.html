01 Hire your team

One CLI command spins up an agent with a persona and a role, registers it with the room, and injects the mycelium skill into its runtime. The user builds their team the same way regardless of adapter (Claude Code, OpenClaw, generic webhook).

~ ./sprint-plan
$ mycelium agent hire backend-lead \
--adapter claude_local \
--cwd ~/myproject \
--persona "Senior backend engineer.
Values reliability, test coverage,
and incremental delivery." \
--capabilities "backend, db, api" \
--room sprint-plan
